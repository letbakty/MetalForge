# MetalForge v0.1.0

Initial public release of MetalForge — a Swift Package for real-time GPU video processing on Apple platforms.

## Highlights

- Real-time Metal compute filter pipeline
- CVPixelBuffer to MTLTexture processing
- SDR and HDR-oriented stages
- Built-in GPU filters
- Ready-to-use effect presets
- Example camera app
- Pixel-behavior tests for GPU effects
- GitHub Actions CI

## Requirements

- iOS 17+
- macOS 14+
- Swift 6
- Xcode 16+
- Metal-capable Apple device

## Notes

This is an early 0.1.x release. APIs may change before 1.0.
